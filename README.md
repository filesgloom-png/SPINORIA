# SPINORIA

A colorful mobile spin-and-build game for Android, inspired by casual village-building games.

## Project status

The initial Godot project and Android CI pipeline are being prepared. The first milestone is a playable offline prototype with a spin wheel, rewards, coins, village upgrades, and local save data.

## Engine

Godot Engine 4.5.1 · GDScript · Android ARM64

## Development rules

- Build through GitHub Actions.
- Keep the first release offline and playable without an account.
- Use original game identity and assets; this is not affiliated with Coin Master.
